# 0007 English as default and project language

**Status:** Proposed

## Context
LuxyOS targets Europe, including the Western Balkans and Turkey. Contributors will come from many countries.

## Decision
English is the default language of LuxyOS and the language of this repository. Launch languages: English, Dutch, Croatian, Bosnian, Serbian, Albanian, Macedonian, Turkish, German, French and Spanish; then all official EU languages.

## Consequences
- All code, issues and documentation are written in English.
- Translations go through Weblate with native-speaker review.
