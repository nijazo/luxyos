# Vision

LuxyOS is a fast, free and honest operating system for people and businesses who want to leave Windows but need things to simply work.

## Principles

1. **Only what is needed runs.** Nothing starts at boot except the broker, the desktop and the login screen. Services, drivers and helpers start on demand and stop when idle.
2. **Closing means closing.** When the last window of a program closes, all its processes stop. Running in the background requires the user's permission.
3. **Nothing leaves without permission.** No telemetry, no advertising ID, no selling of data. Every connection is visible in a privacy overview.
4. **Familiar and easy.** A desktop layout Windows users recognise. No command line needed for normal use. Clear error messages with a solution.
5. **Free and voluntary.** Free to use. Registration is optional. Security updates for everyone.
6. **Choice.** Browser, search engine and antivirus are chosen by the user. Administrators choose whether AI is allowed.
7. **Honest.** Never promise that everything works. Compatibility labels say what works, what partly works and what does not.

## Target groups and launch rule

A target group only gets LuxyOS when **everything on its list works**. If something does not work, users will not use it.

| Order | Target group | Must work |
| --- | --- | --- |
| 1 | **Private**: internet, mail, photos | Browser, e-mail, photos and video, printing, wifi, sleep, updates, phone link |
| 2 | **Business: office work** | Microsoft 365 (web and desktop), Outlook, Teams, PDF, VPN, AD and Entra ID, remote management, printers, security |
| 3 | **Gamers** | Steam and Proton, controllers, GPU drivers, one click to Windows for games with anti-cheat |
| 4 | **Business: engineering and industry** | Adobe, AutoCAD, AVEVA and other professional software |

Business is the biggest opportunity: many companies want to leave Windows, but there is no alternative that really works and is easy to manage.

## What makes LuxyOS different

Existing systems each solve part of the problem (Zorin OS, SteamOS, ChromeOS, ReactOS). None combines:

- on-demand services and real closing of programs;
- privacy as a core promise, with a per-app overview;
- one store for Windows, Linux and GitHub apps, with compatibility labels;
- business features: AD, Remote Desktop, certificates, PowerShell, a package manager and remote management;
- a familiar, simple desktop.

Lesson from Lindows (2001–2008): do not promise that all Windows programs work, and use your own name and design.
