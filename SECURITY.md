# Security policy

LuxyOS has no released code yet, so there are no supported versions.

Report vulnerabilities privately, never in public issues:

- by e-mail to **security@luxyos.com**, or
- through **GitHub's private vulnerability reporting** (Security tab → *Report a vulnerability*), once it is enabled.

This also applies now, for problems in the website luxyos.com or in this repository.

Security principles for LuxyOS are described in [docs/requirements.md](docs/requirements.md) and the decision records in [docs/decisions/](docs/decisions/).
