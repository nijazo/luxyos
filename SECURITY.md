# Security policy

LuxyOS has no released code yet, so there are no supported versions.

When code is published, report vulnerabilities privately through **GitHub's private vulnerability reporting** (Security tab → *Report a vulnerability*), not in public issues. A dedicated address will follow (planned: security@luxyos.com).

Security principles for LuxyOS are described in [docs/requirements.md](docs/requirements.md) and the decision records in [docs/decisions/](docs/decisions/).
